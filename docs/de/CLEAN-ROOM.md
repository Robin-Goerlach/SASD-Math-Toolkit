# Clean-Room-Regel

Das historische Handbuch dient für V1 als Funktionskatalog und fachliche Referenz. Historischer Borland-Quellcode wird nicht kopiert, transkribiert oder in dieses Repository übernommen. Auch längere Handbuchtexte werden nicht übernommen.

Mathematische Verfahren und etablierte Methodennamen werden unabhängig neu implementiert und mit eigenen Tests sowie eigener Dokumentation beschrieben.
