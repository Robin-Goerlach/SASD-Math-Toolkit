# Clean-room / historical-reference policy

The historical *Turbo Pascal Numerical Methods Toolbox* is used as a **functional catalog and documentation reference** for the V1 milestone.

The SASD implementation must remain independently written:

- Do not copy or transcribe Borland source code.
- Do not import historical source files into this repository.
- Do not reproduce substantial copyrighted manual text as project documentation.
- Mathematical algorithms, equations and established method names may be reimplemented from mathematical knowledge and independently written descriptions.
- Tests may use independently derived examples and well-known analytical results.

The goal is a modern functional successor with clean APIs, tests and documentation, not a literal source clone.
